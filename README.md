# Big Ben — Restaurant Bar · Tivat

Website mockup for Big Ben restaurant & pizzeria, Šetalište Seljanovo 21, Tivat.
Languages: EN / RU / ME. Menu data: `menu-data.js` (from bigben.digitalnimeni.me).

## GitHub Pages
1. Upload all files from this folder to the root of a repository (keep the `img` and `icons` folders).
2. Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. The site opens at `https://<username>.github.io/<repository>/`.
